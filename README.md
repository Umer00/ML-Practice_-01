# 🤖 Introduction to Machine Learning

### 📊 Linear Regression — Experience vs Salary

A beginner-friendly Machine Learning practice project that introduces the basic ML workflow and builds a **Linear Regression model** to predict salary based on work experience.

---

## 🎯 Objective

The goal of this practice project is to understand the basic workflow of Machine Learning by creating and training a simple **Linear Regression** model.

The notebook covers:

- Creating a dataset
- Exploring the dataset
- Visualizing the relationship between experience and salary
- Splitting data into training and testing sets
- Training a Linear Regression model
- Making predictions
- Evaluating model performance
- Visualizing the regression line
